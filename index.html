Job 01

Directory-to-intranet identity sync

Kept profiles and group access on a company-wide intranet platform in step with the corporate directory, every night.

Trigger
Nightly
Reads
Active Directory, identity database, rules list
Writes
User profiles and group memberships
Reports
Email summary of every change and failure

WhyThe platform vendor's own identity integration failed security review, so profiles and access had to come from the directory another way.

  • Maps each person's directory attributes into the platform's user format and updates their profile through its REST API.
  • Sets group membership from rules: a leader's direct reports, departments, companies, contractor filters and leadership levels by job title.
  • Keeps the rules in a SharePoint list instead of the code, so adding a group means adding a row.
  • Logs every addition, removal and failure, and emails a summary after each run.

ResultA fully compliant replacement, delivered on schedule.

  • PowerShell
  • REST
  • OAuth 2.0
  • Active Directory
  • SQL
  • SharePoint
  • Bitbucket

Bulk content operations

Job 03

Outage watchdog

Flagged intranet outages within about a minute and recorded how long each one lasted.

Trigger
Every 60 seconds
Reads
Site status, sign-in and page-load time
Writes
Outage and load-time logs (CSV)
Reports
Email alert, then hourly until it recovers

WhySupport needed to hear about an outage as soon as it started, and to have a record of every one.

  • Checks the site every 60 seconds and records when an outage starts and the error it returned.
  • Emails the support team after one minute down, then every hour until the site is back.
  • On recovery, closes the alert and logs total downtime for post-incident reports.
  • A companion probe signs in and times the page load, logging each result.

ResultEvery outage flagged within about a minute, with its duration on record.

  • PowerShell
  • HTTP checks
  • SMTP alerts
  • CSV logging
Job 04

Microsoft 365 data pipelines and audits

Kept SharePoint lists, Teams and Azure AD groups in step with their sources, and reported on the tenant.

Trigger
File drops and on demand
Reads
ERP exports, distribution lists, Microsoft Graph
Writes
SharePoint lists, Teams and group membership
Reports
Emailed run reports, CSV audits

WhyReporting and data upkeep across Microsoft 365 needed to run the same way every time.

  • A Microsoft Graph wrapper shared across jobs, with v1 and beta endpoints, automatic paging and token refresh.
  • An ETL job that loads ERP exports into a SharePoint list. It removes duplicates (keeping the newest), matches records by key, and creates or updates only what's needed.
  • Membership sync that keeps Teams and Azure AD groups in step with distribution lists, reporting lines and office location.
  • Tenant audits: license use with readable SKU names, site permissions with back-off when the API throttles, and Power Platform app and flow owners.

ResultStreamlined enterprise reporting, data management and identity workflows.
